# Как собирать данные с krisha.kz (проверено 23.10.2026)

Опыт сбора паркингов, офисов и квартир Астаны в облачной сессии Claude Code. Готовые скрипты лежат рядом: `krisha_list.py` собирает выдачу, `krisha_detail.py` открывает карточки.

## 1. Инструменты

- **Python `requests` + `beautifulsoup4`.** Установка: `python3 -m pip install --user requests beautifulsoup4`. Обычный `pip` может ставить пакеты в другой Python.
- **Запуск:** `python3 -P -E script.py`. Флаг `-I` не подходит: он отключает user site-packages, и `requests` не найдётся.
- **curl через прокси сессии часто рвётся** (`Connection reset`), requests с повторами работает стабильно.
- **WebFetch** подходит только для разового взгляда на страницу: он пересказывает её маленькой моделью и для массового сбора не годится.

## 2. Адреса выдачи

`https://krisha.kz/<раздел>/<категория>/<регион>/?<фильтры>&page=N` — 20 карточек на странице, плюс 2–3 «горячих» на первой.

| Что | Путь |
|---|---|
| Продажа квартир | `prodazha/kvartiry` |
| Аренда квартир | `arenda/kvartiry` |
| Коммерческая | `prodazha/kommercheskaya-nedvizhimost` |
| Гаражи и паркинги | `prodazha/garazhi` |

**Регионы Астаны** (число объявлений о продаже квартир на 23.10.2026):

| Регион | slug | Квартир |
|---|---|---|
| весь город | `astana` | 37 959 |
| Есиль | `astana-esilskij` | 10 495 |
| Нура | `astana-nura` | 10 177 |
| Алматы | `astana-almatinskij` | 5 987 |
| Сарайшык | `astana-saraishyk` | 4 660 |
| Сарыарка | `astana-saryarkinskij` | 3 904 |
| Байконур | **`r-n-bajkonur`** | 1 496 |

- **Районы покрывают не всё.** В сумме районов около 1,2 тыс. объявлений меньше, чем у города: у части объявлений район не указан. Чтобы ничего не потерять, собирайте по `astana`.
- **Неверный slug ничего не сообщает об ошибке.** krisha молча показывает весь Казахстан (около 223 тыс.). Проверяйте `<title>`: там должно быть «… Астаны» или «в Астане».
- **Slug можно узнать через автодополнение:** `https://krisha.kz/region/ajaxAutocomplete?query=Байконур` (JSON с полем `alias`).

**Число объявлений** берётся из `Найдено <span>37 959</span>`. Пробелы внутри — неразрывные (`\xa0`).

**Фильтры** (имена из формы поиска):
- `das[price][from]` / `das[price][to]`;
- `das[live.rooms][]=2`;
- `das[live.square][from|to]`;
- `das[flat.floor][from|to]`;
- `das[house.year][from|to]`;
- `das[who]=1` — только хозяева;
- `das[novostroiki]`;
- `das[map.complex]=<id ЖК>`;
- `_txt_=<текст>` — поиск по тексту.

**Сортировка:** `sort_by=price-asc` или `sort_by=price-desc`.

## 3. Ограничение 1000 страниц

Выдача отдаёт максимум **1000 страниц** (20 тыс. объявлений). `?page=1500` молча возвращает страницу 1000. Поэтому большой запрос нужно резать на ломтики меньше 19 тыс. объявлений.

`krisha_list.py` делает это сам: делит по цене пополам, пока ломтик не влезет. Для всей Астаны получилось три ломтика: 0–30 млн (13,3 тыс.), 30–60 млн (16,8 тыс.), от 60 млн (8 тыс.). Внутри ломтика сортировка `price-asc`, чтобы порядок не прыгал. Объявления дедуплицируются по `id`: «горячие» повторяются на разных страницах.

## 4. Что есть в карточке выдачи

Селекторы `.a-card[data-id]`:

| Селектор | Пример |
|---|---|
| `.a-card__title` | «2-комнатная квартира · 64.9 м² · 9/9 этаж» → комнаты, площадь, этаж/этажность |
| `.a-card__price` | «29 900 000 ₸» |
| `.a-card__subtitle` | «Сарайшык р-н, Темирбека Жургенова 18/1» |
| `.a-card__text-preview` | «жил. комплекс Аулие-Ата, кирпичный дом, 2018 г.п., состояние: требует ремонта, потолки 2.9м., санузел совмещенный, …» — ЖК, тип дома, год, состояние, потолки по-русски |
| `.a-card__owner-label` | «Хозяин недвижимости» / «Специалист» |
| `.a-card__stats-item` | город, дата («16 окт.») |

Координат в выдаче нет. В `window.data` лежат только id и счётчики.

## 5. Карточка объявления

- **Русская страница `https://krisha.kz/a/show/<id>`** отвечает скриптам кодом **468** (защита). Казахская версия **`https://krisha.kz/kz/a/show/<id>`** отдаётся нормально (200). Её мы и используем.
- **`window.data.advert`** (JSON в `<script id="jsdata">`) — главное:
  - `price`, `rooms`, `square`;
  - `map.lat` и `map.lon` — точные координаты;
  - `complexId`, `addressTitle`, `address.district`;
  - `userType` (owner / specialist / company), `status`.
- **Атрибуты:**
  - где лежат: `.offer__info-item[data-name]` и `dl dt[data-name]` + `dd`;
  - ключи не зависят от языка: `flat.building`, `house.year`, `flat.floor`, `live.square`, `flat.renovation`, `flat.toilet`, `flat.balcony`, `flat.parking`, `ceiling`, `map.complex`, `has_change` (обмен);
  - значения на зеркале казахские («монолитті», «жақында жөндеуден өткен»). Русские формулировки есть в превью выдачи.
- **Описание** — `.a-text`.
- **Страница ЖК:** `https://krisha.kz/complex/show/astana/<slug>/`, блок «Параметры»: количество квартир, этажность, паркинг. Агрегатор часто ошибается, проверяйте цифры.

## 6. Скорость и надёжность

- **Паузы:** 1–2,5 с между запросами на поток. **До 3 потоков параллельно** (`krisha_detail.py --shard k --of 3`) работали без блокировок: 1 036 карточек открылись примерно за 20 минут.
- **Сколько это займёт:** вся выдача Астаны — около 1 900 страниц, примерно час. Карточки всех 38 тыс. объявлений в три потока — примерно 6–8 часов. Открывайте карточки только там, где нужны координаты или описание.
- **Обрывы.** Прокси сессии иногда рвёт туннель (`ConnectionResetError`, в `$HTTPS_PROXY/__agentproxy/status` видно `ws_closed_mid_exchange`). Это лечится повтором с паузой, скрипты так и делают.
- **Возобновление.** Пишите результат построчно в `.jsonl`, а при перезапуске пропускайте уже собранные id: скрипты возобновляемые.
- **Фоновые задачи** живут до 2 часов, длинный сбор запускайте через `nohup … &` и следите за логом.
- **`pkill -f` с шаблоном** из собственной командной строки убивает и саму оболочку. Ищите PID через `ps` и убивайте по номеру.

## 7. Правила

- **Не проходить и не обходить проверки:**
  - капчи, Cloudflare, SafeLine, страницы «Just a moment»;
  - коды 468/403/429 на всех адресах.

  Если видите такое, сбавьте скорость, а если не проходит — остановитесь и скажите пользователю. Сайт bi.group закрыт Cloudflare, его мы не трогали.
- **Без входа в аккаунт.** Не подставлять в запросы почту и другие данные пользователя.
- **Цены в объявлениях — запросы продавцов.** Сделки обычно на 5–15 % ниже.

## 8. Качество данных по квартирам

- **Дубли.** Одну квартиру часто выставляют несколько агентов: сравнивайте ЖК + площадь + этаж + цену и при совпадении держите одну.
- **Выбросы.** Цена за м² сильно ниже или выше района бывает у долей, общежитий (`das[flat.priv_dorm]`), квартир «под обмен», опечаток в цене (лишний ноль).
- **Новостройки и вторичка.** Различаются фильтром `das[novostroiki]` и полем `house.year`.
- **Для новостроек BI и других застройщиков** есть госреестр долевого строительства: `POST https://api.homeportal.kz/api/v1/getobjects` (весь список объектов) и `GET https://api.homeportal.kz/api/v1/objects-detail/<id>`. Там по каждой очереди видно квартиры, проданные квартиры (`no_of_apartments_sold`), комнатность, площади, число машино-мест и дату ввода.

## Скрипты

```bash
cd commercial-analyzer/tools
# вся продажа квартир в Астане, с автоматической нарезкой по цене
nohup python3 -P -E krisha_list.py /path/flats.jsonl --path prodazha/kvartiry --regions astana > list.log 2>&1 &
# только хозяева, 2-комнатные, Есиль
python3 -P -E krisha_list.py out.jsonl --regions astana-esilskij --query 'das[who]=1&das[live.rooms][]=2'
# карточки (координаты, атрибуты, описание) в 3 потока
for k in 0 1 2; do nohup python3 -P -E krisha_detail.py flats.jsonl det_$k.jsonl --shard $k --of 3 > det_$k.log 2>&1 & done
```

Примеры прошлых сборов: `commercial-analyzer/parking_left_bank/scripts/park_list.py`, `park_detail.py` и `commercial-analyzer/exchange_search/scripts/krisha_fetch.py`.
