# Бигвилли BI Group в Астане: аренда и перепродажа коммерции (krisha.kz)

Снимок от 13.10.2026. Для каждого бигвилля собраны объявления krisha.kz
(аренда и продажа коммерческой недвижимости) в прямоугольнике примерно
±500 м вокруг его комплексов. Координаты комплексов взяты с korter.kz
(`data/korter_astana_buildings.json`).

## Как собирали

krisha list-страницы принимают фильтр области на карте:

```
https://krisha.kz/arenda/kommercheskaya-nedvizhimost/astana/?areas=p<lat>,<lon>,<lat>,<lon>,...&page=N
```

Это замкнутый полигон (запятые кодируются как `%2C`). Для продажи тот же
`areas` используется с `/prodazha/`. Поиск по слову (`_txt_=GreenLine`)
находит в 3–4 раза меньше: только объявления, где название бигвилля
написано в тексте. Используемые полигоны записаны в `data/<slug>.json`.

## Расчёт (`bvcalc.py`)

- Отбрасываются цоколь и подвал (по тексту сниппета), площади меньше 15 м²
  (кладовки) и больше 1000 м², неправдоподобные ставки, повторы.
- Ставка аренды — медиана с обрезкой 10% хвостов, в ₸/м²/мес.
- Чистый доход в год = ставка × 0,9 (торг от запрашиваемой) × 0,85
  (простой ~1 мес/год, налог, обслуживание) × 12.
- Предельная цена покупки = чистый доход / целевая доходность (12%, 10%, 8%).
- «own» — только объявления в комплексах самого бигвилля (по названию ЖК).

```
python bvcalc.py data
```
