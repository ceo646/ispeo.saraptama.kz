# Паркинги левого берега Астаны: цены продажи машино-мест (16.10.2026)

Интерактивная карта лежит в `parking_map.html`; её можно открыть в браузере. На ней:
- **Поверхность цен.** Сглаженная, от зелёного (дешевле) к красному (дороже).
- **Точки ЖК.** По клику видны медиана, разброс цен и ссылки на объявления.
- **Рейтинг зон** размером около 1 км.
- **Переключатели:** «за место» / «за м²»; тип паркинга; радиус сглаживания.

## Как собрано

1. **Источник.** Все объявления раздела «Продажа гаражей и паркингов» на krisha.kz по Есильскому и Нура районам: 1 056 объявлений, из них 1 036 с типом «Паркинг».
   - Каждая карточка открыта (`/kz/a/show/`). Из неё взяты точные координаты, число мест, тип паркинга (подземный или наземный), коммуникации и полное описание.
   - Сарайшык — новый район на правом берегу, восточнее Акорды. Он не входит в выборку.
2. **Автоматический допуск.** Без проверки агентами принимались только простые объявления: подземный тип, 1 место, цена 1–20 млн, площадь 9–25 м², без тревожных слов в описании («два места», «кладовка», «аренда», «бокс» и т. п.).
3. **Проверка агентами.** Остальные 602 объявления и 75 случайных «чистых» для контроля разобрали субагенты.
   - Первый агент определял тип места, сколько мест за цену и цену одного места.
   - Второй агент независимо перепроверял все исключения, пересчёты цены и решения с неполной уверенностью — это 539 решений.
   - Контрольная выборка: из 75 «чистых» объявлений 74 подтвердились. Одно оказалось паркингом бизнес-центра.
4. **Что убрано (34):**
   - склады и кладовки;
   - целые паркинги и готовый бизнес;
   - гаражи-боксы;
   - места дешевле 1 млн без явной опечатки;
   - объявления с непонятной ценой за место;
   - дубли;
   - неверные координаты.
5. **Наземные места.** Включались, только если в тексте есть признаки крытого или тёплого паркинга: многоуровневый, отопление, ворота в здание. Таких 270. Ещё 50 наземных без описания показаны на карте отдельным режимом и в расчёты по умолчанию не входят.
6. **Поверхность** — сглаженная медиана соседних ЖК. Это ядерная регрессия: по умолчанию радиус 700 м, вес ЖК растёт с числом объявлений и ограничен. Заливка гаснет на расстоянии 0,55–1,45 радиуса от ближайшего ЖК. Цвет растянут от 5-го до 95-го процентиля.

## Ограничения

- **Цены — запросы продавцов.** Сделки обычно на 5–15 % ниже.
- **Немного объявлений в ЖК.** У многих ЖК 1–3 объявления, поэтому отдельная точка может быть случайной. Зоны и районы надёжнее.
- **Тип наземного паркинга** («крытый» или «открытый») определён по тексту объявления. Без осмотра бывают ошибки.

## Файлы

- `parking_map.html` — карта; подложка из OpenStreetMap (© участники OSM), цены из krisha.kz.
- `data/`:
  - `list.json.gz` — все карточки списка;
  - `details.jsonl.gz` — все 1 036 карточек;
  - `review_decisions.json` — решения обоих агентов;
  - `final_listings.json` — принятые места;
  - `excluded.json` — исключённые места с причинами;
  - `map_listings.json` — данные карты;
  - `basemap.json` — подложка.
- `scripts/`:
  - `park_list.py`, `park_detail.py` — сбор;
  - `park_prep.py` — проверки и пачки для агентов;
  - `park_basemap.py` — подложка;
  - `park_build.py` — сборка карты;
  - `park_zones.py` — рейтинг зон и проверка устойчивости;
  - `template.html` — шаблон страницы.
