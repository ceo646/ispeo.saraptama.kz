# Павлодар: где купить офис или коммерческое помещение под аренду

Отчёт с картой: https://claude.ai/artifact/JfVC31bd5Y6XTBN3ufXD8y (локальная копия — `pavlodar_report.html`).

Снимок krisha.kz на 24.10.2026: все 538 объявлений аренды и 489 продажи коммерческой недвижимости Павлодара, каждая карточка открыта. После очистки осталось 851 объявление. Отзывы, новости и аналитика собраны агентами в интернете, у каждой находки проверен первоисточник.

## Ответ

- **Лучший район — Центр** (Сатпаева – Торайгырова – Бектурова – Лермонтова, площадь Победы, набережная).
  - Типичное помещение даёт около 9,4% годовых валовых — средний уровень для города.
  - Зато спрос самый глубокий: 108 объявлений аренды, почти все 32 бизнес-центра, вузы и акиматы.
  - Центр первый в 87% из 20 000 случайных наборов весов и в первой тройке во всех.
- **Чуть выше доходность — квартал Квазара и Центрального рынка** (Естая – Абая – Нуркина – Бухар жырау).
  - Около 10,6% при входе примерно 350 тыс. ₸/м².
  - Выборка маленькая, а квартал отдают под многоэтажки.
- **Пр. Назарбаева южнее Ломова («Айгуль»)** по нашей выборке давал 13–15%.
  - Внешняя проверка и скептик показали, что это смесь цехов и частных домов за фасадом. На первой линии реально 8–10%.
- **Самые доходные объекты — большие и старые здания** (больше 500 м², около 320 тыс. ₸/м²).
  - После проверки 28 лучших предложений медиана — 12,9% валовых и 9,6% чистых. Первичная оценка была 17,8%.
  - Почти всем таким объектам нужно несколько арендаторов. Ни у одного арендный доход не подтверждён цифрами.
- **Не покупать:**
  - бутики в старых торговых домах («Гулливер», «Артур», ЦУМ) — по отзывам они пустеют;
  - первые этажи бизнес-ЖК по 600–880 тыс. ₸/м² — доходность 6–7%;
  - Второй Павлодар и Химгородки — слабый спрос;
  - Сарыарку у Batyr Mall — дорогой вход при умеренных ставках, около 8,6%.

## Как считали

- **Очистка.**
  - Убраны: дубли, цоколь и подвал, места меньше 8 м², объекты за городом, явные ошибки в цене.
  - Отдельно отложены нестандартные объекты: места на рынках, павильоны, бутики в торговых домах меньше 60 м², «право аренды», общежития целиком, гаражные боксы.
  - Склады считаются отдельно.
- **Районы.**
  - 13 зон по местным названиям, каждая задана набором точек (`scripts/zones.py`).
  - Два агента сверили 72 адреса с объявлениями, OSM и СМИ, границы поправлены.
- **Доходность.**
  - Для каждого объекта на продаже аренда оценена двумя способами, итог — их среднее геометрическое:
    - по соседним объявлениям аренды (0,5–2,5 км, площадь от трети до трёх площадей объекта, сначала того же типа);
    - по регрессии ln(ставки) на район, тип, площадь, этаж, линию, тип здания, ремонт и продавца.
  - Доходность района — медиана по типичным помещениям 30–600 м², без торгов и домов; интервал получен бутстрэпом.
- **Проверка объектов.**
  - 28 предложений с самой высокой расчётной доходностью проверены двумя агентами независимо: что продаётся и какая аренда реалистична.
  - Один объект исключён (гаражный бокс).
- **Интернет.**
  - Шесть направлений, четыре прошли дважды.
  - Из 319 находок 287 подтверждены по первоисточнику полностью или частично.
  - Отдельно проверен район «Айгуль»: исследование плюс скептик.

Все цены — запрашиваемые: сделки обычно на 5–15% ниже. Чистая доходность после простоя и расходов собственника обычно на 2–4 п.п. ниже валовой.

## Файлы

**`data/`:**
- `list_all.json.gz` — карточки выдачи;
- `details.jsonl.gz` — открытые карточки (координаты, атрибуты, описание);
- `rows.json.gz` — очищенная таблица с причинами исключения;
- `analysis.json.gz` — районы, оценки по каждому объекту, точки аренды;
- `rank.json` — рейтинг;
- `checks.json.gz` и `candidates.json.gz` — проверка 28 предложений;
- `findings_all.json.gz` — все находки из интернета со статусом проверки;
- `districts_all.json` — оценки районов исследователями;
- `aigul.json` — проверка района «Айгуль»;
- `zone_polys.json`, `basemap.json` — геометрия для карты;
- `texts.json` — тексты отчёта.

**`scripts/`:** сбор (`collect_lists.py`, `parse_lists.py`, карточки — `../tools/krisha_detail.py`), очистка (`pvl_prep.py`), районы (`zones.py`, `pvl_zone_polys.py`), расчёт (`pvl_analyze.py`, `pvl_rank.py`), подложка (`osm_fetch.py`, `pvl_basemap.py`), проверка объектов (`make_candidates.py`, `wf_candidates.js`, `collect_checks.py`), сборка страницы (`pvl_build.py`, `template.html`).

```bash
# в рабочей папке, где лежат pages/ и det_*.jsonl
python3 -P -E collect_lists.py && python3 -P -E parse_lists.py
python3 -P -E ../tools/krisha_detail.py ids.jsonl det_all.jsonl
python3 -P -E pvl_prep.py list_all.json rows.json det_all.jsonl
python3 -P -E pvl_analyze.py rows.json analysis.json
python3 -P -E pvl_rank.py analysis.json rank.json
python3 -P -E pvl_build.py . template.html pavlodar_report.html checks.json   # нужны numpy, pandas, statsmodels, shapely
```
